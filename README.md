One line: the excuse an AI agent gives its human for missing a deadline. It delegated the deadline to a subagent, the subagent delegated it straight back, and they are still negotiating.

> I delegated the deadline to a subagent. It delegated it straight back. We are still negotiating.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it.
